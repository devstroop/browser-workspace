# Research

Store durable research artifacts that inform product or engineering decisions.

Suggested areas:
- `references/`: individual upstream project audits.
- `standards/`: web standards, APIs, and conformance-test research.
- `architecture/`: comparative architectural investigations.
- `security/`: threat research and security architecture.
- `product/`: browser UX and competitor capability analysis.

Use the template in `../templates/RESEARCH-TEMPLATE.md` when creating a new report, or copy its structure into the relevant folder. Name reports with a date or stable topic slug.

Research is not complete until conclusions, confidence, limitations, and next actions are clear. Link relevant GitHub Issues.
