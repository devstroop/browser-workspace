# Reports

Store generated and human-reviewed reports from research automation, CI, benchmarks, and compatibility analysis.

Prefer reproducible inputs and machine-readable output where useful. Each report should state:
- Generation time and tool version.
- Source revisions and environment.
- Scope and methodology.
- Known limitations.
- Whether findings are automatically generated or human-verified.
- Related issue(s).

Avoid committing large, repetitive artifacts when CI logs or external artifacts are a better fit. Never include credentials, cookies, private browsing content, or personal data.
