# Benchmarks

Store benchmark definitions, scripts, environment descriptions, raw results where appropriate, and analysis.

Report:
- Goal and workload.
- Hardware, OS, power mode, build type, versions, flags, and network conditions.
- Warm/cold state and repetitions.
- Median and spread; include failed runs.
- Memory methodology (RSS, peak RSS, process tree, or other metric).
- Limitations and relevance to actual user experience.

Never claim a general performance win from a single microbenchmark. Keep sensitive browsing data and credentials out of benchmark artifacts.
