# Workspace Tooling

Tools here serve research, planning, automation, or cross-project analysis. They are not product dependencies by default.

For each tool, document:
- Purpose and owner.
- Inputs, outputs, and exit codes.
- Dependencies and supported platforms.
- How to run locally and in CI.
- Data handling and security implications.
- Failure modes and maintenance plan.

Prefer deterministic tools, structured output, clear error reporting, and tests. Do not silently modify product source or create issues from unverified findings.
